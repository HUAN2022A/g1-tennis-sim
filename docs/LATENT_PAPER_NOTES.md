# LATENT 论文调研：人形机器人网球技能学习

调研日期：2026-09-04
论文：Learning Athletic Humanoid Tennis Skills from Imperfect Human Motion Data (arXiv:2603.12686v1, 2026-03-13)
作者：Zhikai Zhang 等（清华大学、北京大学、Galbot Inc.、上海期智研究院、上海AI实验室）
项目页：https://zzk273.github.io/LATENT/
代码：https://github.com/GalaxyGeneralRobotics/LATENT

**与本仓库的关系**：我们使用的网球轨迹数据（`...\LATENT\storage\data\mocap\Tennis\p1`）正是该论文采集的数据；交接文档第 9 节引用的 "AdaPT/LATENT" 即此项目。机器人同为 Unitree G1 29 DoF。

## 1. 任务与核心思路

在 Unitree G1 上实现网球回球任务（连续回击来球到目标落点），真机可与人类多拍对拉。核心思路：

- 完整比赛动作数据难采 → 只采**动作片段**（正手、反手、侧滑步、交叉步等 primitive skills）
- 片段"不完美"：①手腕动作不精确（动捕难度 + 跨本体差异）②不含如何组合运用的任务知识
- 关键洞察：不完美的准真实数据仍提供了网球场景下人类基础技能的先验，经"修正 + 组合"后可学出任务策略

## 2. 数据采集

- 5 名业余球员，光学动捕，场地仅 3m×5m（比全场小 17 倍），共 5 小时，无编辑无标注
- LocoMuJoCo 重定向人 → 人形
- 大幅降低了采集门槛（对比：从真实比赛视频提取的 Vid2Player3D 管线需要检测/相机估计/姿态估计等复杂流程）

## 3. 系统架构（三阶段）

```text
阶段 1  Motion Tracker 预训练（Any2Track 框架）
        RL 跟踪策略 π_tracker(a_body | s_t, s̃_t+1)
        ★ 关键设计：训练时移除右腕（持拍侧）控制信号 + 施加随机扰动，
          使跟踪器在腕部被外部修正时仍保持其余关节稳定
        ↓
阶段 2  在线蒸馏 → 可修正隐动作空间（DAgger）
        encoder-decoder + 变分信息瓶颈（CVAI 风格）
        先验为可学习的状态条件高斯 P(z_p | s_t)（非固定 N(0,1)），
        捕捉不同状态的动作分布差异
        蒸馏期间保持腕部扰动 → 隐空间对修正鲁棒
        ↓
阶段 3  高层策略（50Hz，与低层同频）
        输入：机器人状态 s_t + 根位姿 g_t + 球状态 b_t
        输出：a_planner = [a_latent, a_correct]
          - a_latent：隐动作，从先验附近采样选技能
          - a_correct：直接控制右腕的修正指令
        ★ Latent Action Barrier (LAB)：
          a_full = [D(s_t, μ_p + λσ_p · tanh(a_latent)), a_correct]
          残差隐动作被马氏距离约束在先验均值附近（自适应状态方差），
          防止 RL 采样出不自然的抖动技能组合
```

与我们栈的对应：他们的 Motion Tracker ≈ 我们的 Humanoid-GPT（同为运动跟踪低层）。差距：他们训练跟踪器时就为腕部修正留了接口；我们的 `pns_wo_priv264.onnx` 无此设计。

## 4. 训练设置

- PPO + MuJoCo JAX，8 GPU 并行
- 高层 50Hz / 低层 50Hz，**仿真 2000 Hz**（拍-球接触仅几毫秒）
- Episode：机器人随机初始化于球场 + 准备姿态；每 2 秒发一球，需**连续回击 8 球**到目标位置

## 5. Sim-to-Real（对后续开发最有参考价值）

### 域随机化

| 对象 | 参数 | 范围 |
|---|---|---|
| 机器人 | 脚摩擦 | U(1.0, 2.5) |
| 机器人 | 关节摩擦 ×U(0.75,1.25)，armature ×U(1.0,1.05)，质量 ×U(0.75,1.25)，CoM ±0.05 | |
| 球拍 | 质量 ×U(0.8,1.2)，CoM ±0.1 | |
| 球 | 质量 ×U(0.95,1.05)，地面弹性 U(0.71,0.79)，切向阻尼 U(0.4,0.7)，空气阻力 k U(0.01,0.04) | |

空气阻力显式建模：`f_air = −k·m·v·|v|`。结论：足够的域随机化可替代精确系统辨识。

### 观测噪声

- 球位置加噪 + 帧级 dropout + 延迟
- 球速度由位置差分得到，对噪声极敏感 → **4 帧滑窗平均**作为球速度观测（仿真与真机一致）

### 真机部署

- 无视觉：光学动捕提供机器人（基底刚体标记）与球（反光贴包裹）的全局状态
- 拍用 3D 打印连接件固定在右腕，替换右手

## 6. 结果

**仿真**（10,000 次试验，正手/反手 × 前场/后场）：

| 方法 | 正手 SR | 反手 SR | 前场 SR | 后场 SR |
|---|---|---|---|---|
| vanilla PPO | 不收敛 | — | — | — |
| MotionVAE (Vid2Player3D 式) | 不收敛 | — | — | — |
| AMP | 41.3 | 36.8 | 49.5 | 41.7 |
| ASE | 63.5 | 55.2 | 71.4 | 68.6 |
| PULSE | 71.9 | 63.4 | 74.5 | 72.9 |
| **LATENT** | **96.5** | **82.1** | **86.4** | **89.8** |

SR = 回球落在目标 2.5m 内的比例。消融：去掉腕部修正 SR 显著下降；去掉 LAB 动作抖动加剧。

**真机**（20 次连续对拉）：正手 SR 90.9%（DE 3.15m）、反手 77.8%、前场 88.9%、后场 81.8%。去掉球的 DR 或观测噪声均大幅退化（如 w/o DR 正手仅 16.7%）。

## 7. 对本仓库路线的启示

1. **架构定位正确**：Humanoid-GPT（跟踪低层）+ 高层选择/修正 = LATENT 的层次结构。我们的 #8 高层状态机即其阶段 3 的无学习简化版。
2. **腕部修正是关键**：击球精度的来源是高层直接修腕 + 低层对腕部扰动鲁棒。我们现有 ONNX 跟踪器没有该接口——纯"选片段 + 触发时机"的状态机能验证"命中"，但到不了"回球到落点"的精度（LATENT 消融证明）。
3. **真拍质量**：0.3kg 拍下我们完成率崩到 0.632；LATENT 靠拍质量/CoM 域随机化 + 训练内消化。带拍微调训练（或至少 DR 重训跟踪器）是真拍闭环的前提。
4. **球观测**：来球预测直接抄"4 帧滑窗平均速度 + 位置噪声建模"。
5. **仿真频率**：他们 2000Hz 建模拍-球接触；我们 1000Hz 在 50g 拍 14-15 m/s 下无穿模（#6 结论），重拍/更高拍速需复核，必要时 2000Hz。
6. **推荐两步走**：#8 先做"无学习版"（状态机选片段 + 时机控制，#6 的自然延伸，验证闭环命中），跑通后再评估是否上 RL 微调（需 8 GPU 级资源，可参考其开源训练代码与奖励表）。
