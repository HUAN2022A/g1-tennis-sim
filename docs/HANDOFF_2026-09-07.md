## 3. V3 当前状态（下次优先处理）

V3 今日修了 4 个真实 bug：
1. walk 从网球 onset 姿态起步（walk policy 分布外）→ 改 `reset_to_standing` 站立起步。
2. 到达时 `reset_to_frame` 把飞行中的球 park 掉 → 加 `ball_state` 参数保留球。
3. NO_SWING 门控按 `p_swing` 判偏差（V3 已重定向，不适用）→ 移除。
4. 重定向只平移复位位置、参考轨迹未平移 → 加 `shift_ref_root` 平移 `qpos`+`gv2wrd_pose`。

**诊断结论**（已加 instrumentation 确认）：机器人 walk 正确（到达 nav_target 误差 2.7cm）、重定向 offset 正确，但**挥拍段拍面离球 ~1m**——挥拍没跟踪到重定向后的参考轨迹。

**疑似根因**：walk→teleport 姿态跳变（手臂从垂放到持拍抬起、腿从步行姿切到击球姿）+ `settle_margin=0.25s` 太短，跟踪策略未收敛就挥拍。

**下一步**：逐帧对比实际 vs 参考拍面轨迹（instrumentation），区分是 teleport 不稳还是时序错位；必要时增大 `settle_margin` 或加"到达后先站桩稳定再挥拍"的过渡。
