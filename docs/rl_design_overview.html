1 核心思想：冻结底层 + 只学腕部

底层是一个 冻结的跟踪策略（pns_wo_priv264，136→2048→1024→512→29 + SiLU），在 MJX 批量网球环境里跑 V1 状态机，零残差命中率 62%——这是规则状态机「选片段 + 触发时机」够不着的天花板。

训练的是一个小 MLP，只输出 右腕 3 个关节的修正量 δ，叠加到冻结策略输出上，用强化学习补上命中精度。

依据：LATENT 论文消融证明「腕部修正」是击球/落点精度的关键来源（去掉腕部修正，正手成功率 96.5% → 82.4%）。我们的规则状态机没有这个接口，62% 就是它的极限。

2 架构总览（数据流）

δ 加在 nn_action[26:29]（右腕 roll/pitch/yaw）、nn2motor 之前 —— 这样残差随 last_action 反馈进下一帧观测，复刻 LATENT「低层对腕部修正鲁棒」的闭环结构。

4 残差策略：actor-critic

actor 输出 δ（3 维）· critic 输出 value（GAE 优势估计用）——共享躯干，仅 ~2.3 万参数（对比冻结策略 292 万）。

5 奖励设计

项公式权重作用
r_close峰值窗内 −∥ball−site∥1.0引导拍面贴球（密度 shaping）
r_hit终局命中，摊在最后 active 步+5.0稀疏主信号

吸收态全掩码：done 后 reward=0，绝不计算窗外距离（球 park 于 100m 处会撑爆 value head）。

6 PPO 训练配置

算法

PPO-clip + GAE，状态无关高斯策略。三个关键正确性点：

  • old_params 冻结：collect 后一次性算 logp_old，epoch 内不随更新变化
  • 门控步 logp 剔除：非激活步 δ 被掩为 0，其 logp 是伪值，不参与 loss
  • GAE 吸收态 bootstrap=0：done 处 V=0，逐环境独立

超参

gamma / gae_lambda0.99 / 0.95
clip / vf_coef / ent_coef0.2 / 0.5 / 0.01
lr (Adam) / grad norm3e-4 / 0.5
epochs / minibatch3 / 2048
num_envs / total_iters512 / 2000

7 训练循环 + 门控

训练/评估共用同一 jitted env，靠 noise_on 动态标量区分（train=1 注入探索噪声 / eval=0 确定性），零重编译。

8 结果：命中率 62% → 93%

前 10 个迭代是探索期（随机噪声扰乱跟踪，命中率短暂跌到 32.5%），随后快速爬升，~30 迭代即超过 62% 基线，之后稳定在 90–96% 平台。σ=5mm 随机阻力完整设置。
