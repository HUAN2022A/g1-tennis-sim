## 3. 关键发现（3 个环境坑，已入 RL_STAGE1.md §4 坑 10/11）

1. **jax GPU 默认 tf32（关键，影响训练）**：RTX Ada 上 jax matmul 默认 tf32，冻结策略 flax 推理偏离 f64 精确值 **2.17e-2**（正常 1e-5；onnxruntime 仍 1.67e-5）。**训练/测试必须 `JAX_DEFAULT_MATMUL_PRECISION=highest`**（修复后 flax vs f64 降到 1.10e-5）。
2. **GPU MJX 物理非确定**：同 seed 两次 rollout 球轨迹差 ~0.1-0.2m（contact solver 并行 reduce 混沌放大），逐位复现不可能。determinism 测试改「reset 随机数逐位 + old_logp 统计一致」。
3. **测试阈值 GPU 口径**：GPU cuBLAS 累加顺序与 CPU MKL 不同，f32 累差 ~5e-5；flax↔onnx 对齐阈值按设备自适应（GPU 1e-4 / CPU 1e-5），纯元素语义对齐放宽到 5e-6，update_coord_cmd f64 输入对比 1e-4。

```bash
# 训练（已完成，checkpoint 已保存到 storage/ckpts/rl/residual_ppo.pkl）
sudo docker exec -d -e JAX_DEFAULT_MATMUL_PRECISION=highest hgpt-rl python rl/train_ppo.py --train \
  --num-envs 512 --total-iters 2000 --eval-interval 10 --eval-balls 200 --seed 0 \

sudo docker exec -e JAX_DEFAULT_MATMUL_PRECISION=highest hgpt-rl python rl/train_ppo.py --eval \
  --num-envs 512 --ckpt storage/ckpts/rl/residual_ppo.pkl --n-balls 1000
```
